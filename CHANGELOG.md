# Changelog

All notable changes to Swim BASI are documented here.

## [Unreleased]

### Changed

- Imported 41 verified Printful mockup sets as transparent, optimized WebP product media.
- Mapped front, hover, and ordered gallery views through the central product data and generated image
  manifest.
- Replaced verified homepage, shop, collection-grid, and silhouette-card previews with accessible,
  responsive product mockups while retaining deferred hover loading.
- Preserved the unmatched `red-violet-one-piece` source locally because no corresponding catalog
  product exists.

- Polished customer-facing storefront copy across the homepage and informational pages.
- Replaced product image placeholders with an intentional “Color preview” treatment.
- Consolidated Printful availability, sizing, and checkout disclosure near featured products.
- Removed visible implementation instructions and inactive contact/newsletter form messaging.

- Upgraded Astro from 5.18.1 to 7.1.1 and updated official Astro integrations.
- Standardized local and Cloudflare Pages builds on Node 22.23.1.
- Preserved the prior HTML whitespace behavior during the Astro 7 compiler migration.

### Added

- Initial Astro static storefront scaffold.
- Twelve routes, reusable editorial components, typed product catalog, and filtering utilities.
- Accessible navigation, responsive product grids, SEO foundations, sitemap, robots file, and structured organization data.
- Product, media, deployment, and project documentation.
